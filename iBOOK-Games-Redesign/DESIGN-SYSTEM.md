# iBOOK Games — design system

## Primary palette

- Deep Purple: `#340475`
- Brand Purple: `#5711AC`
- Electric Pink: `#FF299A`
- Sky Cyan: `#13B7E9`
- Ink: `#2F155D`
- Surface: `#F8F7FF`
- White: `#FFFFFF`

The visual language keeps the original purple/blue/pink identity, but introduces clearer hierarchy, gradients, large accessible targets, soft cards, and generous whitespace.

## Component specs

- Navbar: sticky, 76 px desktop / 67 px compact
- Main content: max 1250 px
- Cards: 18–22 px radius, soft shadow, 4-col desktop / 2-col mobile
- Interactive buttons: pill shaped pink primary, white outline secondary
- Detail page: game viewport, tabbed description, learning notes, sidebar, related-game grid
- Mobile: two-column game cards; mobile navigation; stacked game player

## Language

EN/AR toggle works for central navigation and key home hero copy, and toggles RTL; remaining long-form content needs translation review before public release.

## Source assumptions

There are 60 visible game titles and 18 original subject filters. Subject-to-game assignments for this prototype were inferred and should be verified with the game's real database. Grades, ages, play URLs, actual game instructions and curriculum objectives are not in the screenshot and remain intentionally unfilled.
